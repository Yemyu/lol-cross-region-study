# 英雄联盟国际赛表现

[打开网页](https://yemyu.github.io/lol-cross-region-study/)

展示 LPL、LCK 历年世界赛代表队在 MSI 和世界赛中的内外战战绩，支持跨年份、跨队伍的交互比较。

## 网页里有什么

LPL、LCK 和两个赛区合并的三张散点图。每个点是一支队伍在某一年的记录，可以按年份、俱乐部、赛事成绩和最低积分筛选，也可以保留其他队伍作为背景，只突出想看的类别。

点开队伍后，可以看到大场和小局战绩、BO5／BO3／BO1 的分别统计、逐场对手与比分。积分构成和全年比赛时间线放在详情里。统计范围与计分说明位于图表之前，按标签切换。

## 统计范围

- 年度样本：LPL、LCK 世界赛代表队。2012—2025 年有 92 个样本；另有截至 2026-09-27 的 8 个未完年度样本。2011 年没有中韩世界赛参赛样本。
- 比赛：当年 MSI 和世界赛，含相应阶段的有效赛果。只参加 MSI、未取得世界赛资格的队伍不作为年度样本。
- 内战：国际赛中与同赛区队伍的交手。国内联赛不计分。
- 重要外战：中韩相互交手，以及对当年欧洲世界赛一号种子的交手。“全部外战”还包括其余跨赛区对手。
- 欧洲名单按年底身份回顾全年，因此不是赛前预测。2011 年名单特例选 Fnatic，但该年没有中韩样本。

没有交手的方向不是零分。图表用边缘的无交手带区分；两侧都没有比赛的样本保留在列表里，不绘制成点。

## 积分

| 赛制 | MSI 胜／负 | 世界赛 胜／负 |
| --- | --- | --- |
| BO5 | +5 / −2.5 | +7.5 / −3.75 |
| BO3 | +2.5 / −1.25 | +3.5 / −1.75 |
| BO1 | +1 / −0.5 | +2 / −1 |

BO5、BO3 每场另加 `该场胜利基础分 ÷ 6 × 该场小局胜率`，赢或输都计算；BO1 不另补分。内战与外战分别累计。

图表可以在内战比赛分上加两项种子基础分：MSI 一号 3 分、二号 1.5 分；世界赛一至四号种子分别为 4.5、3、1.5、0 分。两项相加，最高 7.5 分。种子指同赛区出线顺位，不是抽签池；早期只有一个 MSI 名额的参赛队按一号种子计分。未参加 MSI、当年取消或尚未创办时，MSI 种子分为 0。

每个年度样本的 MSI 种子身份和来源记录在 `msi-seeds.json`。切换到纯国际赛内战视图时，两项种子分都不计入。

场次多、走得远的队伍有更多得分机会；积分不适合脱离战绩和赛制单独解释。

## 本地打开

下载仓库后，直接用浏览器打开 `index.html`。也可以在仓库目录运行：

```sh
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。页面没有后端，也没有必须安装的前端依赖，D3 已放在 `vendor/`。

## 数据和检查

`data.js` 是当前页面的数据快照；`matches.csv` 和 `summary.csv` 分别保存逐场记录和汇总。每条比赛保留来源链接。

主要来源是 [Games of Legends](https://gol.gg/) 与 [GPTilt / Leaguepedia 比赛快照](https://huggingface.co/datasets/gptilt/lol-esports-matches)，部分资格信息引用 [LoL Esports](https://lolesports.com/)。现有跨来源核对记录在 `international-audit.json`。这个仓库发布当前快照和展示代码，不包含原始网页缓存，也不提供自动追踪新赛果的服务。

运行以下检查，可以从逐场记录重新计算场次、分赛制战绩、积分和种子分，并与 100 个年度样本的汇总比较：

```sh
python3 scripts/check_data.py
```

检查通过只说明记录内部一致，不等于每条原始赛果都已得到独立验证。发现比分、日期、参赛身份或队名有误，可以开 issue，附上队伍、年份和赛果来源。
